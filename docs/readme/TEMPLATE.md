# ETS2 ATS VR Controls: drive Euro Truck Simulator 2 and American Truck Simulator in VR with your VR controllers

> [!CAUTION]
> **Only download this mod from https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases.** There is no website, no Discord,
> no Nexus, no Steam Workshop. Any other site, mirror or "installer" that offers it is not mine: do not run it.

![ETS2 / ATS VR Controls](../images/banner.png)

Play **Euro Truck Simulator 2** and **American Truck Simulator** in VR with **only your headset and its controllers**. No
steering wheel, no gamepad, no keyboard, no mouse.

- **Drive with the controllers:** steer with the stick, with a wheel you hold with one or both hands, or by pointing. The
  triggers are gas and brake.
- **Any key on a button:** indicators, horn, lights ... in four layers (hold a grip for more buttons).
- **A mouse in your hand:** for the game's menus and the map.
- **A full keyboard in the headset**, with the keys of your country's keyboard.
- **The VR menu in your language:** it follows the game's language by itself.

## What you need

- Windows 10 / 11 (64-bit), ETS2 or ATS, and a VR headset (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- The game in its **OpenXR** VR mode. Steam: right-click the game > Properties > Launch options: `-openxr`
  (in the normal game version also `-experimental_vr`). The `-openvr` and `-oculus` modes do not work with this mod.

## Install

1. Download the newest `ETS2-ATS-VR-Controls-....zip` from the
   [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases) page. Close the game.
2. Unzip it to a folder where it can stay (for example `C:\ETS2 ATS VR Controls`).
3. Right-click `install.ps1` > **Run with PowerShell**. Click **Yes** in the Windows admin prompt.
4. Start the game in VR.

At every start the game shows "Request to use advanced SDK features detected". That is this mod (for driving): point at
OK and click.

**The VR menu:** hold **both grips + the left stick click** for 1 second. There you set every button, the mouse, the
steering, the colours and the language.

Uninstall: run `uninstall.ps1` the same way, then delete the folder.
