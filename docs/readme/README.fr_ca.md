# ETS2 ATS VR Controls : conduisez Euro Truck Simulator 2 et American Truck Simulator en réalité virtuelle avec vos manettes VR

> [!CAUTION]
> **Ne téléchargez ce mod que sur https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases.** Il n'y a ni site web, ni Discord,
> ni Nexus, ni Steam Workshop. Tout autre site, miroir ou « installateur » qui l'offre n'est pas de moi : ne l'exécutez pas.

![ETS2 / ATS VR Controls](../images/banner.png)

Jouez à **Euro Truck Simulator 2** et à **American Truck Simulator** en réalité virtuelle avec **seulement votre casque et ses manettes**. Pas
de volant, pas de manette de jeu, pas de clavier, pas de souris.

- **Conduire avec les manettes :** dirigez avec le stick, avec un volant tenu d'une ou des deux mains, ou en pointant. Les
  gâchettes sont l'accélérateur et le frein.
- **N'importe quelle touche sur un bouton :** clignotants, klaxon, phares ... sur quatre couches (maintenez un grip pour avoir plus de boutons).
- **Une souris dans la main :** pour les menus du jeu et la carte.
- **Un clavier complet dans le casque**, avec les touches du clavier de votre pays.
- **Le menu VR dans votre langue :** il suit tout seul la langue du jeu.

## Ce qu'il vous faut

- Windows 10 / 11 (64 bits), ETS2 ou ATS, et un casque de réalité virtuelle (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- Le jeu en mode VR **OpenXR**. Steam : clic droit sur le jeu > Propriétés > Options de lancement : `-openxr`
  (dans la version normale du jeu, aussi `-experimental_vr`). Les modes `-openvr` et `-oculus` ne fonctionnent pas avec ce mod.

## Installation

1. Téléchargez le plus récent `ETS2-ATS-VR-Controls-....zip` depuis la page
   [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases). Fermez le jeu.
2. Décompressez-le dans un dossier où il peut rester (par exemple `C:\ETS2 ATS VR Controls`).
3. Clic droit sur `install.ps1` > **Exécuter avec PowerShell**. Cliquez sur **Oui** dans l'invite administrateur de Windows.
4. Lancez le jeu en VR.

À chaque démarrage, le jeu affiche « Request to use advanced SDK features detected » (demande d'utilisation de
fonctions SDK avancées). C'est ce mod (pour la conduite) : pointez OK et cliquez.

**Le menu VR :** maintenez **les deux grips + le clic du stick gauche** pendant 1 seconde. Vous y réglez chaque bouton, la souris, la
direction, les couleurs et la langue.

Désinstallation : exécutez `uninstall.ps1` de la même façon, puis supprimez le dossier.
