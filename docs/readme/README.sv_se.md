# ETS2 ATS VR Controls: kör Euro Truck Simulator 2 och American Truck Simulator i VR med dina VR-kontroller

> [!CAUTION]
> **Ladda bara ner den här modden från https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases.** Det finns ingen webbplats,
> ingen Discord, ingen Nexus och ingen Steam Workshop. Varje annan sida, spegling eller "installationsprogram" som erbjuder
> den är inte min: kör den inte.

![ETS2 / ATS VR Controls](../images/banner.png)

Spela **Euro Truck Simulator 2** och **American Truck Simulator** i VR med **bara headsetet och dess kontroller**. Ingen
ratt, ingen handkontroll, inget tangentbord, ingen mus.

- **Kör med kontrollerna:** styr med spaken, med en ratt som du håller med en eller båda händerna, eller genom att peka.
  Triggrarna är gas och broms.
- **Valfri tangent på en knapp:** blinkers, signalhorn, ljus ... i fyra lager (håll ett grepp för fler knappar).
- **En mus i handen:** för spelets menyer och kartan.
- **Ett fullständigt tangentbord i headsetet**, med tangenterna från ditt lands tangentbord.
- **VR-menyn på ditt språk:** den följer spelets språk automatiskt.

## Det här behöver du

- Windows 10 / 11 (64-bitars), ETS2 eller ATS och ett VR-headset (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- Spelet i VR-läget **OpenXR**. Steam: högerklicka på spelet > Egenskaper > Startalternativ: `-openxr`
  (i den vanliga spelversionen även `-experimental_vr`). Lägena `-openvr` och `-oculus` fungerar inte med den här modden.

## Installation

1. Ladda ner den senaste `ETS2-ATS-VR-Controls-....zip` från sidan
   [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases). Stäng spelet.
2. Packa upp den i en mapp där den kan ligga kvar (till exempel `C:\ETS2 ATS VR Controls`).
3. Högerklicka på `install.ps1` > **Kör med PowerShell**. Klicka på **Ja** i Windows administratörsfråga.
4. Starta spelet i VR.

Vid varje start visar spelet "Request to use advanced SDK features detected" (begäran om att använda avancerade
SDK-funktioner). Det är den här modden (för körningen): peka på OK och klicka.

**VR-menyn:** håll **båda greppen + klicket på vänster spak** i 1 sekund. Där ställer du in alla knappar, musen,
styrningen, färgerna och språket.

Avinstallera: kör `uninstall.ps1` på samma sätt och radera sedan mappen.
