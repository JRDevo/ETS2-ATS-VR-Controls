# ETS2 ATS VR Controls: gidatu Euro Truck Simulator 2 eta American Truck Simulator VR-n zure VR kontroladoreekin

> [!CAUTION]
> **Deskargatu mod hau https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases helbidetik soilik.** Ez dago webgunerik, ez Discord-ik,
> ez Nexus-ik eta ez Steam Workshop-ik. Eskaintzen duen beste edozein gune, ispilu edo "instalatzaile" ez da nirea: ez exekutatu.

![ETS2 / ATS VR Controls](../images/banner.png)

Jokatu **Euro Truck Simulator 2** eta **American Truck Simulator** VR-n **betaurrekoekin eta haien kontroladoreekin soilik**. Bolanterik,
gamepad-ik, teklaturik eta saguik gabe.

- **Gidatu kontroladoreekin:** biratu stick-arekin, esku batez edo bietaz heltzen duzun bolantearekin, edo seinalatuz. Gatiluak
  gasa eta balazta dira.
- **Edozein tekla botoi batean:** keinukariak, tuta, argiak ... lau geruzatan (eduki sakatuta grip bat botoi gehiago izateko).
- **Sagu bat eskuan:** jokoaren menuetarako eta maparako.
- **Teklatu oso bat betaurrekoetan**, zure herriko teklatuaren teklekin.
- **VR menua zure hizkuntzan:** jokoaren hizkuntza berez jarraitzen du.

## Zer behar duzu

- Windows 10 / 11 (64 biteko), ETS2 edo ATS eta VR betaurrekoak (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- Jokoa **OpenXR** VR moduan. Steam: egin klik eskuineko botoiarekin jokoan > Propietateak > Abiarazteko aukerak: `-openxr`
  (jokoaren bertsio arruntean `-experimental_vr` ere). `-openvr` eta `-oculus` moduek ez dute mod honekin funtzionatzen.

## Instalazioa

1. Deskargatu azken `ETS2-ATS-VR-Controls-....zip` fitxategia
   [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases) orritik. Itxi jokoa.
2. Deskonprimatu betiko geratuko den karpeta batean (adibidez `C:\ETS2 ATS VR Controls`).
3. Egin klik eskuineko botoiarekin `install.ps1` fitxategian > **Exekutatu PowerShell-ekin**. Sakatu **Bai** Windows-eko administratzaile-mezuan.
4. Hasi jokoa VR-n.

Hasiera bakoitzean jokoak "Request to use advanced SDK features detected" erakusten du (SDK-ren eginbide aurreratuak erabiltzeko eskaera detektatu da). Hori mod hau da (gidatzeko): seinalatu
OK eta egin klik.

**VR menua:** eduki sakatuta **bi grip-ak + ezkerreko stick-aren klika** segundo batez. Han ezartzen duzu botoi bakoitza, sagua,
gidatzea, koloreak eta hizkuntza.

Desinstalatzeko: exekutatu `uninstall.ps1` modu berean, eta ezabatu karpeta.
