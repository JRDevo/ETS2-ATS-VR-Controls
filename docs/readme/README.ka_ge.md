# ETS2 ATS VR Controls: ატარეთ Euro Truck Simulator 2 და American Truck Simulator VR-ში თქვენი VR კონტროლერებით

> [!CAUTION]
> **ეს მოდი ჩამოტვირთეთ მხოლოდ აქედან: https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases.** არ არსებობს ვებსაიტი, Discord,
> Nexus ან Steam Workshop. ნებისმიერი სხვა საიტი, სარკე ან „ინსტალერი“, რომელიც მას გთავაზობთ, ჩემი არ არის: ნუ გაუშვებთ.

![ETS2 / ATS VR Controls](../images/banner.png)

ითამაშეთ **Euro Truck Simulator 2** და **American Truck Simulator** VR-ში **მხოლოდ ჰედსეტითა და მისი კონტროლერებით**. არც
საჭე, არც გეიმპადი, არც კლავიატურა, არც მაუსი.

- **ატარეთ კონტროლერებით:** მართეთ სტიკით, ერთი ან ორი ხელით დაჭერილი საჭით ან მიმართვით. ტრიგერები
  გაზი და მუხრუჭია.
- **ნებისმიერი კლავიში ღილაკზე:** მაჩვენებლები, საყვირი, განათება ... ოთხ შრეში (გრიპის დაჭერით მეტი ღილაკი გაქვთ).
- **მაუსი თქვენს ხელში:** თამაშის მენიუებისა და რუკისთვის.
- **სრული კლავიატურა ჰედსეტში**, თქვენი ქვეყნის კლავიატურის კლავიშებით.
- **VR მენიუ თქვენს ენაზე:** ის თავად მისდევს თამაშის ენას.

## რა გჭირდებათ

- Windows 10 / 11 (64-ბიტიანი), ETS2 ან ATS და VR ჰედსეტი (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- თამაში **OpenXR** VR რეჟიმში. Steam: დააწკაპუნეთ თამაშზე მარჯვენა ღილაკით > Properties > Launch options: `-openxr`
  (თამაშის ჩვეულებრივ ვერსიაში ასევე `-experimental_vr`). რეჟიმები `-openvr` და `-oculus` ამ მოდთან არ მუშაობს.

## ინსტალაცია

1. გვერდიდან [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases) ჩამოტვირთეთ უახლესი `ETS2-ATS-VR-Controls-....zip`.
   დახურეთ თამაში.
2. ამოარქივეთ საქაღალდეში, სადაც შეიძლება დარჩეს (მაგალითად `C:\ETS2 ATS VR Controls`).
3. დააწკაპუნეთ `install.ps1`-ზე მარჯვენა ღილაკით > **Run with PowerShell**. Windows-ის ადმინისტრატორის მოთხოვნაში დააჭირეთ **დიახ**-ს.
4. გაუშვით თამაში VR-ში.

ყოველ გაშვებაზე თამაში აჩვენებს „Request to use advanced SDK features detected“ (მოთხოვნა გაფართოებული SDK ფუნქციების
გამოსაყენებლად). ეს ეს მოდია (სატარებლად): მიუთითეთ OK-ზე და დააწკაპუნეთ.

**VR მენიუ:** დააჭირეთ და 1 წამი ეჭიროთ **ორივე გრიპს + მარცხენა სტიკის დაჭერას**. იქ აყენებთ ყველა ღილაკს, მაუსს,
მართვას, ფერებსა და ენას.

წაშლა: ანალოგიურად გაუშვით `uninstall.ps1`, შემდეგ წაშალეთ საქაღალდე.
