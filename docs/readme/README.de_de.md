# ETS2 ATS VR Controls: Euro Truck Simulator 2 und American Truck Simulator in VR mit deinen VR-Controllern fahren

> [!CAUTION]
> **Lade diese Mod nur von https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases herunter.** Es gibt keine Website, keinen Discord,
> kein Nexus und keinen Steam Workshop. Jede andere Seite, jeder Mirror und jeder „Installer“, der sie anbietet, stammt nicht von mir: Führe ihn nicht aus.

![ETS2 / ATS VR Controls](../images/banner.png)

Spiele **Euro Truck Simulator 2** und **American Truck Simulator** in VR **nur mit deinem Headset und dessen Controllern**. Kein
Lenkrad, kein Gamepad, keine Tastatur, keine Maus.

- **Mit den Controllern fahren:** Lenke mit dem Stick, mit einem Lenkrad, das du mit einer oder beiden Händen hältst, oder durch Zeigen. Die
  Trigger sind Gas und Bremse.
- **Jede Taste auf einem Button:** Blinker, Hupe, Licht ... in vier Ebenen (halte einen Griff für mehr Buttons).
- **Eine Maus in der Hand:** für die Menüs des Spiels und die Karte.
- **Eine volle Tastatur im Headset** mit den Tasten der Tastatur deines Landes.
- **Das VR-Menü in deiner Sprache:** Es folgt von selbst der Sprache des Spiels.

## Was du brauchst

- Windows 10 / 11 (64 Bit), ETS2 oder ATS und ein VR-Headset (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- Das Spiel im **OpenXR**-VR-Modus. Steam: Rechtsklick auf das Spiel > Eigenschaften > Startoptionen: `-openxr`
  (in der normalen Spielversion auch `-experimental_vr`). Die Modi `-openvr` und `-oculus` funktionieren mit dieser Mod nicht.

## Installation

1. Lade die neueste `ETS2-ATS-VR-Controls-....zip` von der Seite
   [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases) herunter. Schließe das Spiel.
2. Entpacke sie in einen Ordner, in dem sie bleiben kann (zum Beispiel `C:\ETS2 ATS VR Controls`).
3. Rechtsklick auf `install.ps1` > **Mit PowerShell ausführen**. Klicke in der Windows-Administratorabfrage auf **Ja**.
4. Starte das Spiel in VR.

Bei jedem Start zeigt das Spiel „Request to use advanced SDK features detected“ (Anforderung zur Nutzung erweiterter SDK-Funktionen erkannt). Das ist diese Mod (fürs Fahren): Zeige auf
OK und klicke.

**Das VR-Menü:** Halte **beide Griffe + den Klick des linken Sticks** 1 Sekunde lang gedrückt. Dort stellst du jeden Button, die Maus,
die Lenkung, die Farben und die Sprache ein.

Deinstallieren: Führe `uninstall.ps1` auf die gleiche Weise aus und lösche dann den Ordner.
