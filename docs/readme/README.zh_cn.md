# ETS2 ATS VR Controls：用 VR 手柄在 VR 中驾驶《欧洲卡车模拟 2》（Euro Truck Simulator 2）和《美国卡车模拟》（American Truck Simulator）

> [!CAUTION]
> **只能从 https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases 下载此 mod。** 没有网站、没有 Discord、
> 没有 Nexus、也没有 Steam 创意工坊。任何其他提供它的网站、镜像或“安装程序”都不是我发布的：请不要运行。

![ETS2 / ATS VR Controls](../images/banner.png)

**只用头显和它的手柄**，就能在 VR 中游玩 **Euro Truck Simulator 2** 和 **American Truck Simulator**。不需要方向盘、
游戏手柄、键盘和鼠标。

- **用手柄驾驶：** 用摇杆转向，或用单手或双手握住的方向盘转向，也可以用指向的方式。扳机就是油门和刹车。
- **任意按键绑定到手柄按钮：** 转向灯、喇叭、车灯 ……共四层（按住握把可使用更多按钮）。
- **手中的鼠标：** 用于游戏菜单和地图。
- **头显中的完整键盘**，按键与你所在国家的键盘一致。
- **VR 菜单使用你的语言：** 自动跟随游戏的语言。

## 你需要什么

- Windows 10 / 11（64 位）、ETS2 或 ATS，以及一台 VR 头显（Quest、Index、Vive、Pico、Windows Mixed Reality ……）。
- 游戏使用 **OpenXR** VR 模式。Steam：右键点击游戏 > 属性 > 启动选项：`-openxr`
  （普通版游戏还要加 `-experimental_vr`）。`-openvr` 和 `-oculus` 模式无法配合此 mod 使用。

## 安装

1. 从 [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases) 页面下载最新的 `ETS2-ATS-VR-Controls-....zip`。
   关闭游戏。
2. 解压到一个可以长期保留的文件夹（例如 `C:\ETS2 ATS VR Controls`）。
3. 右键点击 `install.ps1` > **使用 PowerShell 运行**。在 Windows 的管理员权限提示中点击 **是**。
4. 在 VR 中启动游戏。

每次启动时，游戏都会显示“Request to use advanced SDK features detected”（检测到使用高级 SDK 功能的请求）。这就是此 mod
（用于驾驶）：指向 OK 并点击。

**VR 菜单：** 同时按住**两个握把 + 左摇杆按下** 1 秒。在这里可以设置每个按钮、鼠标、转向、颜色和语言。

卸载：以同样的方式运行 `uninstall.ps1`，然后删除该文件夹。
