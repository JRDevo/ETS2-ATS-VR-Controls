# ETS2 ATS VR Controls: sõida Euro Truck Simulator 2 ja American Truck Simulator VR-is oma VR-kontrolleritega

> [!CAUTION]
> **Laadi see mod alla ainult aadressilt https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases.** Veebilehte, Discordi,
> Nexust ega Steam Workshopi ei ole. Iga teine sait, peegel või „installer“, mis seda pakub, ei ole minu oma: ära käivita seda.

![ETS2 / ATS VR Controls](../images/banner.png)

Mängi **Euro Truck Simulator 2** ja **American Truck Simulator** VR-is **ainult peakomplekti ja selle kontrolleritega**. Ei mingit
rooli, mängupulti, klaviatuuri ega hiirt.

- **Sõida kontrolleritega:** roolid kangiga, rooliga, mida hoiad ühe või kahe käega, või osutades. Päästikud
  on gaas ja pidur.
- **Iga klahv nupul:** suunatuled, signaal, tuled ... neljas kihis (hoia grip-nuppu all, et saada rohkem nuppe).
- **Hiir käes:** mängu menüüde ja kaardi jaoks.
- **Täisklaviatuur peakomplektis** sinu riigi klaviatuuri klahvidega.
- **VR-menüü sinu keeles:** see järgib mängu keelt ise.

## Mida vaja on

- Windows 10 / 11 (64-bitine), ETS2 või ATS ja VR-peakomplekt (Quest, Index, Vive, Pico, Windows Mixed Reality ...).
- Mäng **OpenXR** VR-režiimis. Steam: paremklõps mängul > Atribuudid > Käivitusvalikud: `-openxr`
  (mängu tavaversioonis ka `-experimental_vr`). Režiimid `-openvr` ja `-oculus` selle modiga ei tööta.

## Paigaldus

1. Laadi leheküljelt [Releases](https://github.com/JRDevo/ETS2-ATS-VR-Controls/releases) alla uusim
   `ETS2-ATS-VR-Controls-....zip`. Sulge mäng.
2. Paki see lahti kausta, kus see võib jääda (näiteks `C:\ETS2 ATS VR Controls`).
3. Paremklõps failil `install.ps1` > **Käivita PowerShellis**. Klõpsa Windowsi administraatoriviibal **Jah**.
4. Käivita mäng VR-is.

Igal käivitusel näitab mäng teadet „Request to use advanced SDK features detected“ (tuvastati taotlus kasutada SDK täiustatud funktsioone). See on see mod (sõitmiseks): osuta
nupule OK ja klõpsa.

**VR-menüü:** hoia **mõlemat grip-nuppu** + **vasaku kangi klõpsu** 1 sekundi vältel all. Seal seadistad iga nupu, hiire,
roolimise, värvid ja keele.

Eemaldamine: käivita `uninstall.ps1` samamoodi, siis kustuta kaust.
